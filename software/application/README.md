# Application software

- **Target / operating system:** MATLAB desktop; recorded run on macOS. Exact macOS and computer model were not recorded.
- **Runtime / dependencies:** MATLAB R2026a Update 4 with Symbolic Math Toolbox 26.1. Other versions and operating systems have not been verified.
- **Installation:** Download or clone the complete repository; install and enable MATLAB and Symbolic Math Toolbox.
- **Configuration:** Parameters are in the entry functions in [simulation/](../../simulation/).
- **Run:** Set the repository root as Current Folder and run [RUN_ALL.m](../../RUN_ALL.m). See [simulation instructions](../../simulation/README.md) for generated results and playback controls.
- **Credentials:** No credentials are required in the source files.
