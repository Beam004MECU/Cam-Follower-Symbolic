# Media

- `links_joints.png`: main model with link and joint labels.
- `main_matlab.png`, `bonus_matlab.png`: images generated by the verified MATLAB run.
- `main_mechanism.avi`, `bonus_mechanism.avi`: MATLAB recordings recompressed as MJPEG at 1050 × 650 for download (frame count and timing preserved), 3 seconds and three revolutions each. Download the AVI files to play them.
- `stepped_synthesis.png`: independent Python calculation preview.

Playback controls are installed after AVI recording and therefore do not appear in the saved recordings.
